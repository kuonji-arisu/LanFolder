# LanFolder

[English](README.md) | [中文](README.zh-CN.md)

LanFolder 是一个小型桌面应用，用来在可信的局域网内把一个本地文件夹分享给附近设备。

这个项目最开始是我为了自己的使用场景 vibe coding 出来的：我想在电脑、手机和平板之间快速传文件，但不想配置 SMB、不想插线，也不想通过聊天软件或云服务中转。

它不是完整的文件服务器、NAS、同步服务，也不是面向公网的应用。它只是一个简单的局域网小工具：桌面端负责控制分享，其他设备通过浏览器访问文件管理页面。

## 功能

- 在局域网内通过 HTTP 分享一个选定的本地文件夹
- 在桌面应用里显示可访问的局域网地址
- 手机、平板或另一台电脑可以用浏览器打开分享页面
- 浏览和下载文件
- 在开启上传权限时上传文件
- 在开启上传权限时新建文件夹
- 在开启管理权限时删除文件
- 删除的文件会移动到 `.lanfolder/trash`
- 在局域网设备之间发送短文本消息
- 消息存储在 `.lanfolder/messages.jsonl`
- 在桌面应用里显示最近访问日志
- 默认隐藏点文件
- 可选择关闭窗口后继续保留在托盘
- 可选择启动后自动开始分享

## 权限等级

LanFolder 有三种权限模式。

### `readonly`

局域网内的设备可以浏览和下载文件。

这是默认推荐的安全模式。

### `upload`

局域网内的设备可以浏览、下载、上传文件，并新建文件夹。

适合在可信设备之间接收文件。

### `manage`

局域网内的设备可以浏览、下载、上传、新建文件夹，并删除文件。

删除的文件会移动到 `.lanfolder/trash`，而不是直接移除。

只建议在可信网络中使用这个模式。

## 安全模型

LanFolder 面向可信局域网设计，例如家庭 Wi-Fi、私人热点，或你自己的设备之间临时组成的局域网。

它不提供认证机制。任何能访问桌面应用中显示的局域网地址的设备，都可以使用当前选择的权限等级。

服务器默认会拒绝非私有网络地址的访问，并阻止跨站写入请求，但这些检查不能替代认证。不要把 LanFolder 暴露到公网，也不要在有不可信设备的网络中使用。

建议默认使用 `readonly`，只有在你信任当前网络和周围设备时，再切换到 `upload` 或 `manage`。

## 托管目录

LanFolder 会在共享文件夹中创建一个保留目录 `.lanfolder`，用于存放应用管理的数据：

```text
.lanfolder/
├── trash/
└── messages.jsonl
````

`.lanfolder` 会从局域网文件 API 中隐藏，不能通过浏览器页面访问或删除。

## 项目范围

LanFolder 首先是一个个人工具。目标是保持小巧、直接、好用。

代码仍然会尽量认真处理高风险部分，尤其是文件系统相关行为：路径穿越、符号链接逃逸、保留目录、上传文件名、避免覆盖已有文件、隐藏文件和删除行为。

## 技术栈

* Go
* Wails 3
* Vue 3
* TypeScript
* Pinia
* Tailwind CSS
* shadcn-vue 风格组件

## 开发

要求：

* Go
* pnpm
* Wails 3

安装前端依赖：

```bash
cd frontend
pnpm install
```

以开发模式运行：

```bash
cd ..
wails3 dev
```

构建：

```bash
wails3 build
```

运行检查：

```bash
go test ./...
cd frontend
pnpm test
pnpm build
```
